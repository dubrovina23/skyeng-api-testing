# Как изучить и при необходимости запустить коллекцию

1. Импортируйте файл `postman/Skyeng_API_Личные_события.public.postman_collection.json` в Postman.
2. Без авторизации можно изучать структуру папок, запросы и JavaScript-тесты.
3. Для выполнения запросов потребуется **собственная разрешённая тестовая учётная запись**.
4. В публичной копии переменная `baseUrl` содержит адрес API, `eventId` — пустой, `token` — **пустой**. Реальный токен не включён.
5. Настройте переменную `token` **локально**, используя защищённый секрет Postman Vault (например, `myToken`). В заголовок `Cookie` коллекция подставляет `token_global={{token}}`. Не сохраняйте действующее значение токена в синхронизируемых переменных или в экспортируемом файле.
6. Сначала проверьте один **читающий** запрос получения расписания. Только после проверки авторизации и прав доступа переходите к остальным сценариям.
7. Запуск сценариев `createPersonal` создаёт события; используйте тестовые даты и убедитесь, что у вас есть безопасный способ удалить только созданные вами события.

**Важно:** экспортированная коллекция — снимок учебной работы от **16 ноября 2026 года**. Финальная папка локальной очистки, настроенная позже, здесь намеренно не распространяется.
