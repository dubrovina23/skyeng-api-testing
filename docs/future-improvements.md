# План улучшений

Рекомендации на будущее после зачёта курсовой:

1. Добавить явные проверки ожидаемых HTTP-статусов во все негативные сценарии.
2. Расширить негативные проверки за пределы `title`: граница длины названия в 40 символов, невалидные даты и цвета, несуществующий ID.
3. Уточнить ожидания по телам ответов и кодам ошибок при валидации.
4. Отделять результаты API-тестирования от дефектов UI при формировании общего вывода о релизе.
5. Подготовить очищенные от личных данных скриншоты тест-рана и публичные копии тест-кейсов.

Это **план**, а не заявление о том, что дополнительные тесты уже выполнены.
