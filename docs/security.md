# Правила безопасной публикации

Публичный экспорт подготовлен из учебной коллекции с удалением метаданных Postman и всех ссылок на автогенерированные `auth_secret_*`. В качестве авторизации оставлен **только шаблон** `token_global={{token}}`; `token` публикуется пустым.

**Нельзя добавлять в репозиторий:**
- действующие токены, cookie, секреты Postman Vault или экспорты с их значениями;
- ответы API с идентификаторами пользователей, персональными данными или реальными расписаниями;
- файлы массового удаления с ID чужих или реальных событий;
- скриншоты, на которых видны email, токены, персональные данные или внутренние идентификаторы;
- учебные материалы, на публикацию которых нет разрешения.

Перед каждым `git push` проверяйте `git diff --cached` и настройки доступа к репозиторию. Замена секретов в новых коммитах не удаляет уже опубликованные значения из истории Git.
