## Выводы

В рамках выполненных позитивных и негативных проверок новые критические API-дефекты не обнаружены. В частности, были проверены получение расписания, создание событий, сохранение полей и обработка ряда некорректных значений `title`.

Область тестирования ограничена перечисленными сценариями. Результаты **не означают**, что API проверен во всех граничных условиях или что продукт в целом готов к релизу.

Ранее зарегистрированные UI-дефекты рассматривались отдельно и должны учитываться при итоговой оценке готовности к релизу.

## Очистка данных

После окончания тестирования подтверждена обработка **39 удалений** тестовых событий через API: одно пробное и ещё 38 в Postman Runner. Скрипты массового удаления и файлы с конкретными ID в публичный репозиторий не включены во избежание случайного применения на чужих данных.

## Ограничения

Результаты зафиксированы на момент учебного прогона, а не являются оценкой текущего состояния API. Для повторного тестирования потребуются актуальные данные, разрешённый доступ и проверка ожидаемых результатов.
